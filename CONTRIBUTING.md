# Reporting issues in JvmScope

JvmScope is developed and maintained solely by RobbanHoglund. Bug reports,
documentation corrections and feature suggestions are welcome through
[GitHub Issues](https://github.com/RobbanHoglund/JvmScope/issues).

**External code and documentation contributions are not accepted. Pull requests
are disabled.** The maintainer implements changes and decides the project's
scope and releases. Reporting an issue does not guarantee an implementation,
response time or support commitment.

## Report a problem

Use [GitHub Issues](https://github.com/RobbanHoglund/JvmScope/issues) for ordinary
bugs. Include the JvmScope revision, browser and operating system, input format,
Java version/vendor when known, reproduction steps, and expected versus actual
behavior. Distinguish an incorrect analysis from missing information in a dump.

**Never attach production logs, private thread dumps, credentials or personal
data.** Prefer a minimal synthetic fixture or a capture from a controlled
program. Redaction alone may miss hostnames, certificates, thread names, paths
and application data. Report security issues through [SECURITY.md](SECURITY.md),
not a public issue.

## Suggest an improvement

Open an issue describing the problem you want to solve, the behavior you would
like and a concrete use case. Report documentation errors in the same way.
Please do not submit patches or use issues to bypass the contribution policy.
